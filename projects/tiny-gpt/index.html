Tiny GPT From Scratch

2026 · Personal project

A GPT in pure NumPy with every gradient written by hand, checked by 56 tests.

A character-level GPT built in pure NumPy, with no PyTorch and no autograd. One codebase grows from a counting bigram model into a full Transformer: tokenizer, numerically stable softmax, multi-head causal self-attention, pre-LN Transformer blocks, Adam, and temperature and top-k sampling. Every backward pass is written by hand. The steps started as exercises on Deep-ML; the repository assembles them into one runnable model and adds a test suite that checks each gradient against finite differences.

Details

  • Hand-written forward and backward passes for embeddings, multi-head causal attention, LayerNorm, feed-forward blocks, and the language-model head
  • 56 pytest tests, including a finite-difference gradient check on every model parameter and an end-to-end causality test
  • GitHub Actions runs the test suite and a train-and-sample demo on every push

Built with

Python · NumPy · pytest · GitHub Actions
