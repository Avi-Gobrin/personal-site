Tiny GPT From Scratch

Personal project

A character-level GPT in pure NumPy, with no PyTorch and no autograd: multi-head causal attention, pre-LN Transformer blocks, Adam, and top-k sampling, each with a backward pass written by hand. A 56-test suite checks every parameter's gradient against finite differences, and CI runs it on every push.

F1 Race Winner Predictor

Personal project

Predicts Formula 1 race winners from recent form, qualifying, track history, reliability, and weather, using LASSO-penalized logistic regression on official timing data. Tested walk-forward, each season predicted only from the ones before it, it reaches 40 to 46% winner accuracy: competitive with, though not clearly ahead of, the strong rule that the pole-sitter wins.

Python · FastF1 · scikit-learn · LASSO · factor analysis
