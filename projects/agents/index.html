Autonomous Planning & Knowledge Agents

2026 · Personal project

Two LLM agents run my day and my coursework. Daily planning went from about 30 minutes to under 2.

Two LLM agents that run my day and my coursework, built on Claude Code with an Obsidian vault as the knowledge store. The planning agent runs on its own at the start and end of each day: it reviews what I completed, writes structured notes on the day, and regenerates a time-blocked calendar for the next day from a parsed task file and a traffic-light priority scheme. A companion school-workflow agent auto-formats lecture and problem-set notes into a cross-linked knowledge base of theorem references, so relevant earlier material surfaces when I need it for homework or exams.

Details

  • Cut daily planning from about 30 minutes to under 2
  • Evening review writes structured notes on the day; the next day's calendar is regenerated from a parsed task file and a traffic-light priority scheme
  • School-workflow agent auto-formats lecture and problem-set notes into a cross-linked knowledge base of theorem references, surfacing relevant prior material for homework and exam preparation
