Personal project

Tiny GPT From Scratch

A character-level GPT in pure NumPy with no autograd: multi-head causal attention, pre-LN Transformer blocks, Adam, and top-k sampling, with a hand-written backward pass for every layer. A 56-test pytest suite checks every parameter's gradient against finite differences and runs in CI on every push.

Built with Python, NumPy, pytest, and GitHub Actions.

Personal project

Autonomous Planning & Knowledge Agents

Two LLM agents built on Claude Code, with an Obsidian vault as the knowledge store. The planning agent runs at the start and end of each day, reviews what got done, and regenerates a time-blocked calendar for tomorrow; it cut daily planning from about 30 minutes to under 2. A companion agent turns lecture and problem-set notes into a cross-linked knowledge base of theorem references.

Built with Claude Code, Obsidian, and LLM agents.
