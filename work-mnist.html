Neural Network from Scratch (MNIST)

Python · NumPy · Backpropagation

NumPyNeural NetworksBackpropagationMNISTFrom Scratch

A two-layer feedforward neural network that classifies MNIST handwritten digits, implemented in pure NumPy. The forward pass, loss, and every gradient in the backward pass are derived by hand and coded directly, with no autograd framework involved. The goal was to understand backpropagation from first principles by building it rather than calling it.

Key Details

  • Two-layer feedforward architecture trained on MNIST digit classification
  • All gradient and backpropagation updates derived and implemented by hand in pure NumPy
  • No PyTorch or TensorFlow: the full training loop is written from scratch
